# skills-library-curation

README describes existing cross-platform agents, skills, hooks and MCP configurations. Inventory existing skill names, licenses, hooks and hashes. Use Skill Creator/Installer and Plugin Creator as available; prefer existing equivalents, verify canonical source https://github.com/openai/plugins and pin reviewed revisions. Scan scripts and MCP endpoints before activation; no automatic execution of downloaded hooks, secrets or broad permissions. Record candidate, verified, installed and tested separately. Do not replace upstream Claude Code configuration wholesale.

## Execution contract
Read repo instructions and existing skills first. Prefer tools already installed; external plugins are candidates until connected and approved. Keep implementation and independent QA separate. Record exact commands, results, commit SHA, blockers and rollback. No production deploy, live writes or secret transfer. Source reference: https://github.com/openai/plugins. This is an original repo-specific skill, not a copy or proof of upstream plugin installation.
